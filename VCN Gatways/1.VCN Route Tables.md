## Summary of OCI Route Tables

### **What is a Route Table?**
A route table determines how traffic is routed when leaving a subnet. It's essential for communication **outside** the VCN.

### **Key Characteristics**
- **Subnet Association**: Each subnet has **one** route table
- **Default Behavior**: If no route table is specified, the VCN's default route table is used
- **Rule Priority**: More specific CIDR blocks take precedence over less specific ones
  - Example: `10.0.0.0/24` beats `0.0.0.0/0` for matching traffic
- **Traffic Within VCN**: No route rules needed - this happens automatically

### **Route Rule Components**
Each route rule has two main parts:
1. **Destination CIDR Block** (IPv4) or **IPv6 Prefix**
2. **Route Target** (Next Hop Gateway)

### **Gateway Types - The "Next Hop" Options**

| Gateway Type | Purpose | Traffic Direction | Use Case |
|--------------|---------|-------------------|----------|
| **Internet Gateway** | Public internet access | Bidirectional | Web servers, public APIs |
| **NAT Gateway** | Outbound internet for private resources | Outbound only | Private instances needing updates |
| **Dynamic Routing Gateway (DRG)** | On-premises connectivity | Bidirectional | VPN or FastConnect to datacenter |
| **Service Gateway** | OCI services access | Bidirectional | Object Storage, Autonomous DB |
| **Local Peering Gateway** | Same-region VCN connectivity | Bidirectional | Multi-VCN architectures |
| **Private IP** | Internal routing/firewall | Bidirectional | Custom security appliances |

### **Important Notes**
- **Service Gateway Advantage**: Traffic stays within OCI backbone - more secure and potentially faster
- **IPv6 Support**: Requires specific IPv6 route rules (can't use IPv4 quad-zero)
- **Security Combo**: Route tables + Security Lists work together for complete network security
- **Cross-tenancy**: Possible with proper IAM permissions on both tenancies

### **Practical Example**
```bash
# Route Table Example:
Destination        Target
0.0.0.0/0         Internet Gateway
10.0.0.0/16       DRG (for on-premises)
192.168.0.0/24    Local Peering Gateway
```

This lesson provides a solid foundation for understanding OCI networking routing. The gateway explanations are particularly helpful for choosing the right connectivity solution for different scenarios.
